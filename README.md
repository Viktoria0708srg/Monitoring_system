# АСУР — Мониторинг ИТ-инфраструктуры таможенных пунктов пропуска

Проект представляет собой интерактивный дашборд для мониторинга состояния ИТ-инфраструктуры на пунктах пропуска (ПП). Включает в себя визуализацию данных о видеокамерах, серверах, каналах связи и активных инцидентах.

## 🛠 Стек технологий

**Frontend:**
*   React (TypeScript)
*   Vite (сборщик)
*   Ant Design (UI-компоненты)
*   @ant-design/plots (графики)
*   React Router DOM (навигация)

**Backend (в разработке):**
*   Python (FastAPI)

**3D (в разработке):**
*   Blender

## 📂 Структура проекта

*   `frontend/` — клиентская часть (React)
*   `backend/` — серверная часть (Python)
*   `blender/` — 3D-модели и сцены

## 🚀 Как запустить Frontend

1. Убедитесь, что у вас установлен **Node.js** (версия LTS).
2. Перейдите в папку с фронтендом:
   cd frontend
3. Установите зависимости:
   npm install --legacy-peer-deps
4. Запустите сервер разработки:
   npm run dev
